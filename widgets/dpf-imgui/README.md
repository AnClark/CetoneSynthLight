# dpf-imgui

This is a subset of DISTRHO's [DPF-Widgets](https://github.com/DISTRHO/DPF-Widgets) repository, containing only the ImGui-based widgets, for convenience. These are used in our Classic Series RE plugin for the user interface.

For more details on DPF-Widgets, including the full set of available widgets and their usage, please refer to the original repository.
